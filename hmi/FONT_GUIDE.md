# Как сделать новый шрифт для DWIN (yoRadio)

Рабочий эталон: `27_ubuntu_20_26.bin` (классический ASCII `.bin`, без заголовка `DGUS_2`).  
Нерабочие: файлы из ASCII Font Tool DGUS V7 (`16 bit` / `256 bit`) — начинаются с `DGUS_2`.

Прошивка пишет scroll в **VP+3** (`5000`→`5003`, `5040`→`5043`). В DGUS у виджета указывайте VP **`5000`** / **`5040`**.

---

## Вариант A — самый надёжный (рекомендуется)

Используйте уже проверенный шрифт **27** на оба поля.

1. Скопируйте `27_ubuntu_20_26.bin` в `DWIN_SET` проекта.
2. В **Scrolling text**:
   - FONT0_ID = **27**
   - FONT1_ID = **27**
   - Number of lattice X = **20**
   - Number of lattice Y = **26**
   - Coding mode = **8bit**
3. Generate → прошейте дисплей с microSD.

Второй «новый» шрифт не обязателен: оба scroll могут ссылаться на один ID.

---

## Вариант B — заводской шрифт #0 (латиница без своего .bin)

По мануалу T5L на панели уже есть ASCII **#0** (размеры 4×8 … 64×128).

1. FONT0_ID = **0**, FONT1_ID = **0**
2. Lattice = одна из пар half-width, например **16×32** или **12×24**
3. Coding = **8bit**

Кириллицы в #0 обычно нет — только латиница/цифры.

---

## Вариант C — свой новый `.bin` (классический формат)

Цель: файл **как 27** (в HEX в начале нули, **нет** строки `DGUS_2`).

### 1) Какой tool открывать

В меню DGUS Config Tool:

| Tool | Использовать? |
|---|---|
| **0# word bank generating** | Да — для классического ASCII bank |
| Gray Word Library Generator | Нет — для gray/AA текста |
| ascii font tool (только 16/256 bit) | Нет — даёт `DGUS_2`, у вас кракозябры |
| unicode font | Нет — нужен режим UNICODE в виджете и другая прошивка |

### 2) Генерация

1. Откройте **0# word bank generating**.
2. Выберите TTF (Ubuntu и т.п.).
3. Задайте размер точечной матрицы (для совместимости с текущими полями удобно **20×26**, как у 27).
4. Generate / Save.
5. Проверьте файл в HEX-редакторе:
   - **хорошо:** начало `00 00 00 00 ...`
   - **плохо:** начало `44 47 55 53 5F 32` (`DGUS_2`) — такой файл для Scroll 8bit не брать.

### 3) Имя файла и ID (ячейки по 256 KB)

Имя: **`ID` + необязательное имя**, например:

- `28.bin`
- `28_ubuntu_20_26.bin`

ID шрифтов: **0…47**. Одна ячейка Flash = **256 KB**.

| Размер файла | Сколько ID занимает |
|---|---|
| ≤ 256 KB | 1 |
| 256…512 KB | 2 |
| … | `ceil(size / 256 KB)` |

Пример: файл на ID **27** весит 40 KB → занят только **27**. Следующий свободный — **28**.  
Если бы 27 был 300 KB → заняты 27 и 28, следующий — **29**.

Не ставьте новый ID внутрь занятого блока предыдущего большого файла.

### 4) Положить в проект и прошить панель

1. Файл → в папку **`DWIN_SET`** проекта HMI.
2. В DGUS у Scroll Text:
   - FONT0_ID / FONT1_ID = ваш ID (например **28**)
   - Lattice X/Y = **точные** размеры из генератора (для копии 27: **20 / 26**)
   - Coding mode = **8bit**
3. **Generate** всего проекта.
4. Скопировать содержимое `DWIN_SET` на FAT32 microSD.
5. Дисплей **выключить** → вставить SD → включить → дождаться обновления → вынуть SD.

Правка только в DGUS без прошивки панели шрифт на экране не обновляет.

### 5) Проверка

- Латиница (`progressive`, `SECTOR`) читается.
- В Serial при смене станции: `[DWIN] scroll widget=0x5000 data=0x5003 ...`
- Если снова кракозябры — снова откройте `.bin` в HEX: не должен быть `DGUS_2`.

---

## Настройки Scroll Text (шпаргалка)

| Поле | Станция | Трек |
|---|---|---|
| VP в DGUS | `5000` | `5040` |
| Куда пишет ESP | `5003` | `5043` |
| Coding | 8bit | 8bit |
| FONT0 / FONT1 | 27 (или ваш классический ID) | то же |
| Lattice X/Y | 20 / 26 (для шрифта 27) | то же |

---

## Чего не делать

- Не брать шрифты только с выбором **16 bit / 256 bit**, если HEX = `DGUS_2`.
- Не ставить Lattice 20×26 на шрифт 16×32.
- Не путать VP виджета (`5000`) с адресом данных (`5003`) — в Tool всегда `5000`.
- Не ждать кириллицу от заводского **#0** или от ASCII-банка без кириллических глифов в TTF.

---

## Если «0# word bank» тоже выдаёт DGUS_2

Тогда на этой версии DGUS классический BIN уже не генерируется. Рабочие пути:

1. Копировать/переименовать готовый **27** (при необходимости как `30_....bin` — тот же формат).
2. Искать старый установщик DGUS / Font Maker той версии, которой делали WS-ART (`27_ubuntu_20_26.bin`).
3. Для латиницы — FONT **0**.
