# Playlist — page 2

Фон статичный. На экране **7 фиксированных слотов** (строк). Пагинация только меняет **данные** в этих слотах.

Page id: **2**. Вход с Player: VP `5400` key **`0005`**.

## 14 полей: 7× номер + 7× имя

| Слот (строка) | Номер (Data Variable Int) | Имя (Text Display, 8bit) |
|---:|---:|---:|
| 0 | **`52D0`** | **`5100`** |
| 1 | **`52D1`** | **`5140`** |
| 2 | **`52D2`** | **`5180`** |
| 3 | **`52D3`** | **`51C0`** |
| 4 | **`52D4`** | **`5200`** |
| 5 | **`52D5`** | **`5240`** |
| 6 | **`52D6`** | **`5280`** |

- Номер: Int, 2 bytes, digits 1…3, пустой слот = `0`.
- Имя: **Text Display**, **Text Length = 64** (или меньше, но ≤ 64), 8bit, FONT с кириллицей.
- Прошивка перед записью затирает поле пробелами на всю длину — иначе короткий текст оставляет хвост старого.
- Не Scroll Text.

### Частые ошибки DGUS (по скринам)

| Симптом | Причина | Исправление |
|---|---|---|
| Имя обрезано до 6 символов | Text Length = `6` | Поставить **32** на всех 7 именах |
| Пагинация без лога | **Data auto-uploading OFF** | Включить галочку на keys `0018`/`0019` |
| Тап строки без лога | HMI не прошит / Hold Time 0 / кнопка под текстом | auto-upload ON, Hold Time **1**, Generate→SD, кнопка поверх строки |

Дополнительно (опционально):

| VP | Смысл |
|---:|---|
| `52C0` | текущий выбранный номер станции (1…N) |
| `52C1` | индекс подсвеченной строки в окне **0…6** |

## Как работает пагинация и тап

Слоты **не привязаны** к станциям 1…7 навсегда. Есть `base` = номер первой видимой станции.

```
слот i  →  станция (base + i)
тап key (17+i)  →  play(base + i)
```

При листании (±1 или ±7) меняются только значения в 14 полях.  
**Кнопки тапа не перенастраиваешь** — key `0011` всегда = «верхняя видимая строка», что бы там ни было написано.

Пример: `base=8` → на экране станции 8…14. Тап по 3-й строке (key `0014`) → play **#11**.

Да: тап по строке **сразу включает** эту станцию и возвращает на Player.

## Кнопки (все VP `5400`, auto-upload ON, Page switching `-1`)

| Key (hex) | Key (dec) | Действие |
|---|---:|---|
| `0004` | 4 | назад на Player |
| `0002` / `0003` | 2 / 3 | курсор −1 / +1 (окно едет) |
| `0001` | 1 | play выбранной (курсор) |
| `0011`…`0017` | 17…23 | тап слот 0…6 → play |
| `0018` / `0019` | 24 / 25 | страница −7 / +7 |

На каждую строку — один прозрачный **Return Key Code** на всю ширину (номер+имя), key из таблицы выше. Отдельные тапы на номер и имя не нужны.

## Проверка Serial

```
[DWIN] playlist window base=1 sel=4 row=3 len=42
[DWIN] command=17   ← тап слот 0 → play #1
[DWIN] command=25   ← page down, base станет 8
[DWIN] command=17   ← снова тап слот 0 → уже play #8
```
