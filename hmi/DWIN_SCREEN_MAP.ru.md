# Карта экранов и переменных DWIN

[English](DWIN_SCREEN_MAP.md) · **Русский**

Справочник для дисплея `DMG10600C070_03WTC` (1024×600). Здесь описаны номера страниц, адреса переменных (VP) и типичные ошибки сборки HMI.

Первый экран Player: [MINIMAL_PLAYER.ru.md](MINIMAL_PLAYER.ru.md).

## Адреса переменных

Все переменные приложения лежат в диапазоне от `0x5000` и выше.

Два системных регистра панели (их не занимать под свои виджеты):

| Адрес | Назначение |
|---:|---|
| `0x0082` | Яркость экрана |
| `0x0084` | Номер текущей страницы |

Для кнопок и полей используйте только адреса из этого документа (и из `dwin_vp.h`).

## Страницы

| № | Назначение |
|---:|---|
| 0 | Загрузка |
| 1 | Player |
| 2 | Плейлист |
| 3 | Настройки (хаб) |
| 4 | Wi‑Fi |
| 5 | Звук / эквалайзер |
| 6 | Часовой пояс |
| 7 | О системе |
| 8 | Заставка |
| 9 | Резерв |
| 10 | Будильники (список) |
| 11 | Будильник (редактор) |
| 21…27 | Английские варианты страниц 1…7 (по желанию) |
| 30 / 31 | Английские варианты будильников (по желанию) |

При потере Wi‑Fi и при регулировке громкости прошивка **остаётся на Player** (страницу 9 не открывает).

Яркость экрана настраивается **в самом дисплее** (меню DGUS). На страницу настроек её выносить не нужно.

## Что дисплей шлёт на ESP

Команды — через кнопку **Return Key Code**, адрес `0x5400`, auto-upload включён. Страницу кнопкой **не** переключать (Page switching = −1) — это делает прошивка.

| Значение key | Действие |
|---:|---|
| 1 | Play / Stop |
| 2 / 3 | Предыдущая / следующая станция |
| 4 / 5 | Открыть Player / Плейлист |
| 6…10 | Настройки / Wi‑Fi / Звук / Время / О системе |
| 11 / 12 | Выключить экран / разбудить |
| 15 / 16 | Громкость − / + |
| 17…23 | В плейлисте: играть видимую строку 0…6 |
| 24 / 25 | Плейлист: страница −7 / +7 |
| 26 | Вкл/выкл Telnet CLI |
| 27 | Список будильников |
| 28…30 | Редактор будильника 1…3 |
| 31…33 | Дни: ежедневно / будни / выходные |
| 34 / 35 | Отложить / выключить будильник |
| 36…42 | Переключить день Вс…Сб |

Другие адреса ввода:

| VP | Назначение |
|---:|---|
| `0x5402` | Номер станции для воспроизведения |
| `0x5404` | Громкость 0…254 |
| `0x5406` / `08` / `0A` / `0C` | EQ и баланс (сразу в звук) |
| `0x5410` / `12` | Часовой пояс |
| `0x5416` | Telnet вкл/выкл |
| `0x5420`…`0x542A` | Поля редактора будильника |
| `0x542C` | Открыть редактор слота 0…2 |
| `0x5500` / `0x5540` | SSID / пароль Wi‑Fi |

На странице плейлиста клавиши 2 / 3 / 1 двигают список и запускают выбранную станцию (не «пред./след. по эфиру»).

После каждой команды на `0x5400` прошивка записывает туда `0`, чтобы то же нажатие сработало снова.

## Кнопка Play в DGUS Tool

| Поле | Правильно | Частая ошибка |
|---|---|---|
| VP | `5400` | `50D6` (это только картинка) |
| Key value | `1` | `5400` (тогда команда = 21504) |
| Data auto-upload | ON | OFF — кадр не уходит |
| Button effect | только внешний вид | Путают с key value |

Ожидаемый кадр с дисплея:

```
5A A5 06 83 54 00 01 00 01
```

Иконка Play/Pause (`0x50D6`) обновляется **после** реального старта или остановки, а не в момент нажатия.

## Если что-то не работает

Включите в `myoptions.h`: `DWIN_DEBUG 1`, монитор порта 115200.

При старте в логе должно быть `LINK OK`. Если `LINK FAIL` — прошивка повторит попытку примерно каждые 2 секунды; до успешного ответа дисплея интерфейс не поднимается.

| Симптом | Что проверить |
|---|---|
| Нет связи с дисплеем | Проводка: DWIN TX→GPIO4, DWIN RX→GPIO2, общий GND; джампер UART2 = TTL |
| `LINK OK`, но кнопки молчат | HMI не прошит на панель: Generate → SD → цикл питания с картой |
| `command=21504` | В кнопке Key value должен быть `1`, не `5400` |
| Касание есть, звука нет | Wi‑Fi, плейлист, PCM5102 (SCK модуля на землю) |
| Play срабатывает один раз | Нужна свежая прошивка (сброс `0x5400` в 0) |

Правки в DGUS Tool сами на панель не попадают — нужен microSD с `DWIN_SET`.

## Подключение

| ESP32-S3 | DWIN | Назначение |
|---|---|---|
| GPIO2 | RX | ESP → дисплей |
| GPIO4 | TX | Дисплей → ESP |
| GND | GND | Земля |
| 5V | 5V | Питание панели |

UART 115200, логика 3.3 V. Джампер UART2 = **TTL/CMOS**.

| ESP32-S3 | PCM5102 | Назначение |
|---|---|---|
| GPIO5 | BCK | Тактовый сигнал |
| GPIO6 | LCK / WS | Выбор канала |
| GPIO7 | DIN | Данные |
| GND | SCK | Обязательно на землю (без внешнего MCLK) |
| GND | GND | Земля |

Выход модуля линейный — нужен усилитель или активная колонка.

Пины задаются в [`yoRadio/myoptions.h`](../yoRadio/myoptions.h).
