# Настройки и связанные экраны

[English](SETTINGS_PAGE.md) · **Русский**

Яркость экрана настраивается **в меню самого дисплея**, не через ESP. На эту страницу VP яркости не кладём.

Страница **3**. Вход с Player: VP `5400`, key `0006`.

Все кнопки: Return Key Code, VP `5400`, auto-upload ON, Page switching = −1 (страницу меняет прошивка).

## Страница 3 — хаб

| Кнопка | Key | Куда |
|---|---:|---|
| Назад / Player | `0004` | Страница 1 |
| Звук / EQ | `0008` | Страница 5 |
| Время | `0009` | Страница 6 |
| Сеть | `0007` | Страница 4 |
| О системе | `000A` | Страница 7 |
| Будильники | `001B` | Страница 10 |
| Выкл. экран | `000B` | Гасит подсветку |

По желанию на хабе: RSSI `50A0`, краткий IP/SSID (`50B0` / `56A0`).

Не размещать здесь: яркость, API погоды, IR, загрузку плейлиста.

## Страница 5 — звук (EQ)

Изменения слышны **сразу**, отдельная кнопка «Сохранить» не нужна.

| Показ | VP | Ввод | Диапазон |
|---|---:|---|---|
| Басы | `5302` | `5406` | −40…+6 дБ |
| Середина | `5304` | `5408` | −40…+6 дБ |
| Высокие | `5306` | `540A` | −40…+6 дБ |
| Баланс | `5308` | `540C` | −16…+16 |
| Громкость (опц.) | `50D4` | `5404` или keys 15/16 | 0…254 |

В DGUS: тип Int (со знаком), auto-upload ON, Min/Max как в таблице.

Вход: key `0008`. Назад: `0006` или `0004`.

## Telnet — это не веб

В веб-настройках флаг «Telnet server» включает **консоль на порту 23**, а не веб-страницу. Сайт `/settings.html` работает отдельно.

На хаб или Info можно положить:

| Виджет | VP |
|---|---:|
| Состояние (иконка 0/1) | `5320` |
| Переключатель | `5416` (пишет 0/1) |
| или кнопка | `5400` key `001A` (26) |

Подпись на экране: «Telnet CLI», не «Веб».

## Страница 6 — время

| Показ | VP | Ввод |
|---|---:|---|
| Смещение, часы | `530A` | `5410` |
| Смещение, минуты | `530C` | `5412` |
| Часы / дата (только показ) | `5080` / `5090` | — |

Назад: `0006` / `0004`.

## Страница 4 — Wi‑Fi

Без экранной клавиатуры в первой версии:

- SSID `5500`, IP на `50B0`
- RSSI `50A0`
- Смена сети — через веб `/settings.html`

## Страница 7 — О системе

| Поле | VP | Пример |
|---|---:|---|
| Версия | `5660` | `0.9.720` |
| IP | `50B0` | `192.168.1.10` |
| SSID | `56A0` | имя сети |
| RSSI | `50A0` | `-67 dBm` |
| Битрейт | `50C0` | `320` |
| Формат | `50E0` | `AAC` |
| Режим | `5640` | `WEB` / `SD` |
| № станции | `50D8` | число |
| Часы / дата / день | `5080` / `5090` / `50F0` | |

## Порядок сборки

1. Страница 3 (хаб).
2. Страница 5 (звук).
3. Страница 6 (время).
4. Страницы 10 / 11 (будильники).
5. Страницы 4 / 7 по желанию.
6. Generate → microSD → прошивка дисплея.
