# Будильники — page 10 (список) и page 11 (редактор)

[English](ALARMS_PAGE.md) · **Русский**

Три независимых будильника. Хранение: SPIFFS `/data/alarms.bin` (не EEPROM). При конфликте пересечения окон включённых будильников в одни и те же дни изменение **не применяется молча** — на экране текст «Конфликт с №N», поля остаются прежними.

Page id: **10** (`ALARMS`), **11** (`ALARM_EDIT`). Вход с хаба Settings: VP `5400`, key **`001B`** (27).

Все кнопки: Return Key Code, VP **`5400`**, auto-upload ON, **Page switching = -1**.

## Поведение

| Параметр | Значение |
|---|---|
| Слотов | 3 |
| Дни | bitmask `tm_wday`: bit0=Вс … bit6=Сб |
| Пресеты | ежедневно `0x7F`, Пн–Пт `0x3E`, СбВс `0x41` |
| Старт / стоп | минуты суток 0…1439 (можно через полночь) |
| Станция | номер в плейлисте (с 1) |
| Громкость | 0…254 |
| Отложить | 10 минут (`ALARM_SNOOZE`) |
| Выключить | стоп сессии (`ALARM_DISMISS`) |
| Автостоп | по `stopMin`, если сессия ещё активна |

## Page 10 — список

| Виджет | VP | Тип |
|---|---:|---|
| Слот 0…2: enabled | `5700` / `5720` / `5740` | word 0/1 |
| startMin / stopMin | `+0x02` / `+0x04` | word |
| station / volume / days | `+0x06` / `+0x08` / `+0x0A` | word |
| Строка-сводка | `5800` / `5840` / `5880` | text, Length ≥ 40 |
| Баннер статуса | `58E0` | text, Length ≥ 32 |
| Активность | `5780` | 0=idle, 1=играет, 2=отложено |
| № активного | `5782` | 1…3 (0 если idle) |

| Кнопка | Key | Действие |
|---|---:|---|
| Назад / Settings | `0006` | page 3 |
| Player | `0004` | page 1 |
| Редактор №1/2/3 | `001C` / `001D` / `001E` | page 11, слот 0/1/2 |
| Отложить / Выкл. | `0022` / `0023` | snooze / dismiss (если сессия) |

Альтернатива открыть редактор: записать `0…2` в VP **`542C`**.

## Page 11 — редактор

Правки применяются сразу. При конфликте — текст на `58C0`, значение на дисплее откатывается прошивкой.

| Показ | VP | Ввод (DWIN→ESP) | Диапазон |
|---|---:|---|---|
| № слота (0…2) | `5760` | — | read-only |
| Вкл | `5762` | `5420` | 0/1 |
| Старт (мин) | `5764` | `5422` | 0…1439 |
| Стоп (мин) | `5766` | `5424` | 0…1439 |
| Станция | `5768` | `5426` | 1…N |
| Громкость | `576A` | `5428` | 0…254 |
| Days bitmask | `576C` | `542A` | 0…0x7F |
| Иконки дней Вс…Сб | `5770`…`5776` | keys `0024`…`002A` | toggle bit |
| Ошибка / конфликт | `58C0` | — | text, Length ≥ 32 |

| Кнопка | Key | Действие |
|---|---:|---|
| Назад к списку | `001B` | OPEN_ALARMS |
| Ежедневно / Пн–Пт / СбВс | `001F` / `0020` / `0021` | пресет дней |
| Toggle Вс…Сб | `0024`…`002A` | XOR дня |
| Отложить / Выкл. | `0022` / `0023` | snooze / dismiss |

Для времени удобны Drag/IncDec на `5422`/`5424` с шагом 1 или 5; на экране можно дополнительно показать `HH:MM` через локальный DGUS Math или два поля час/мин с записью минут суток.

## Команды `0x5400`

| Key (dec) | Command |
|---:|---|
| 27 | OPEN_ALARMS |
| 28 / 29 / 30 | ALARM_EDIT_0 / 1 / 2 |
| 31 / 32 / 33 | DAYS daily / weekdays / weekend |
| 34 / 35 | SNOOZE / DISMISS |
| 36…42 | TOGGLE_DAY Sun…Sat |

## Хаб Settings

Добавьте кнопку «Будильники» на page 3: VP `5400`, key **`001B`**.

## Порядок сборки HMI

1. Page 10 список (3 строки + кнопки редактора).
2. Page 11 редактор (поля + дни + ошибка).
3. Кнопка на page 3.
4. На Player опционально Text `58E0` / иконка `5780` + кнопки snooze/dismiss.
5. Generate → SD → прошивка дисплея.
