# Будильники

[English](ALARMS_PAGE.md) · **Русский**

Три независимых будильника. Настройки хранятся в файле на SPIFFS (`/data/alarms.bin`).

Если два включённых будильника пересекаются по времени в одни и те же дни, изменение **не применяется молча**: на экране появляется «Конфликт с №N», поля остаются как были.

Страницы: **10** — список, **11** — редактор. Вход с настроек: кнопка VP `5400`, key `001B` (27).

Все кнопки: Return Key Code, VP `5400`, auto-upload ON, Page switching = −1.

## Как работает

| Параметр | Значение |
|---|---|
| Количество | 3 |
| Дни | Вс…Сб (можно выбрать по одному или пресетом) |
| Пресеты | Ежедневно / Пн–Пт / Сб–Вс |
| Старт и стоп | Время суток; допускается переход через полночь |
| Станция | Номер в плейлисте (с 1) |
| Громкость | 0…254 |
| Отложить | 10 минут |
| Выключить | Остановить воспроизведение будильника |
| Автостоп | В момент времени «стоп», если будильник ещё играет |

## Страница 10 — список

| Что на экране | VP |
|---|---:|
| Вкл/выкл слотов 1…3 | `5700` / `5720` / `5740` |
| Время старта / стопа | следующие адреса (+2 / +4 от базы слота) |
| Станция, громкость, дни | +6 / +8 / +A |
| Текстовая сводка | `5800` / `5840` / `5880` (длина ≥ 40) |
| Статус на Player | `58E0` |
| Идёт будильник / отложен | `5780` (0 / 1 / 2) |
| Номер активного | `5782` (1…3) |

| Кнопка | Key | Действие |
|---|---:|---|
| Назад к настройкам | `0006` | Страница 3 |
| Player | `0004` | Страница 1 |
| Редактор 1 / 2 / 3 | `001C` / `001D` / `001E` | Страница 11 |
| Отложить / Выкл. | `0022` / `0023` | Пока будильник активен |

Редактор также открывается записью `0…2` в VP `542C`.

## Страница 11 — редактор

Изменения применяются сразу. При конфликте — текст на `58C0`, прежние значения возвращаются на экран.

| Поле | Показ | Ввод | Диапазон |
|---|---:|---:|---|
| Номер слота | `5760` | — | только чтение |
| Включён | `5762` | `5420` | 0 / 1 |
| Старт (минуты суток) | `5764` | `5422` | 0…1439 |
| Стоп | `5766` | `5424` | 0…1439 |
| Станция | `5768` | `5426` | 1…N |
| Громкость | `576A` | `5428` | 0…254 |
| Маска дней | `576C` | `542A` | биты Вс…Сб |
| Иконки дней | `5770`…`5776` | клавиши `0024`…`002A` | вкл/выкл дня |
| Ошибка | `58C0` | — | текст ≥ 32 |

| Кнопка | Key | Действие |
|---|---:|---|
| К списку | `001B` | Страница 10 |
| Ежедневно / Пн–Пт / Сб–Вс | `001F` / `0020` / `0021` | Пресет дней |
| День Вс…Сб | `0024`…`002A` | Переключить день |
| Отложить / Выкл. | `0022` / `0023` | Как на списке |

Время удобно крутить IncDec на `5422` / `5424` (шаг 1 или 5). На экране рядом можно показать `ЧЧ:ММ`.

## Команды на `0x5400`

| Key | Действие |
|---:|---|
| 27 | Список будильников |
| 28 / 29 / 30 | Редактор слота 1 / 2 / 3 |
| 31 / 32 / 33 | Пресет дней |
| 34 / 35 | Отложить / выключить |
| 36…42 | День Вс…Сб |

## Хаб настроек

На странице 3 добавьте кнопку «Будильники»: VP `5400`, key `001B`.

## Порядок сборки

1. Страница 10 (список).
2. Страница 11 (редактор).
3. Кнопка на странице 3.
4. На Player по желанию: статус `58E0`, иконка `5780`, кнопки отложить/выкл.
5. Generate → microSD → прошивка дисплея.
